# @deepseek-ai/dsh-client-ui-images

[English](README.md) | 中文

## 概述

在专用 Content 会话中创作图像和视频。图像创作及编辑使用已配置的 dsh-image-gen 服务；视频创作使用已安装的 ComfyUI 工作流。发送前，可将已保存媒体添加到聊天、同时附加多个文件，或把参考媒体拖入输入框。Content 保留现有会话，并使用与工作区聊天相同的输入框、审批和输出卡片。

## 使用此包

打开 Content。如果 dsh-image-gen 不可用，打开 Plugins，安装 dsh-image-gen@latest，启用它并配置服务提供商。返回 Content 并点击刷新。插件负责生成设置和媒体展示；专用页面不会检查 ComfyUI 工作流或为你选择模型。

新图像会话会创建或选择空的持久会话，不会提交生成请求。会话可以重新打开、归档、恢复和导出。新会话使用 Content 模式和用户配置的默认模型，并保留当前主会话的工作目录。它们不会复制主会话选中的模型；工作区聊天使用 API 模型时，新 Content 会话不会因此转向该 API。新 Content 会话会在接受输入前，通过已记录的权限命令选择完全访问权限。ui-images 的 permissionPreset 配置可以改变此默认值；现有会话保留原有权限。ui-images 的 agentPreset 配置选择会话的组合（默认为 content），不会改变工作区聊天的默认模式。已保存的会话保留原有预设；要使用 Content 模式，请新建图像会话。现有会话日志及浏览器本地会话导航保持不变。

<a id="understand-the-implementation"></a>

Studio 将会话与可复用媒体库并排展示；Library 展开图库，不会关闭输入框或清空草稿。创意卡片为一个空输入框填入可编辑的需求说明，不会提交请求或替换已有草稿。搜索筛选已加载的文件名及最近运行的提示词；图片和视频筛选限制可见的选择范围。点击选择，可同时附加多个文件、下载 ZIP 或确认批量删除。删除失败的文件及其选中状态会保留。展开引擎状态，可查看连接设置及启动、停止或重启进度。本地服务器运行前，图像聊天及参考编辑不可用；已保存会话、本地照片、下载及选择仍可使用。状态检查间隔由 serverStatusPollIntervalMs 设置（默认 10000 毫秒，最小 1000 毫秒）。

## 理解实现

<details>
<summary>实现细节 — 点击展开</summary>

CommunityImagesPanel 检查用户配置的插件包列表，并渲染常驻 Conversation 工厂，包括标准输入框。新请求不会添加工作流目录或自编的生成指令。图像插件通过现有注册提供其正常工具和客户端卡片。默认 Web 组合禁用 Arya 的旧 images_generate 工具，避免相互竞争的生成路径。历史 Images 提示仍可正常显示，不会重写持久日志。

旧的直接生成组件和控制器保留在源码中以兼容现有实现；页面在 Studio 和 Library 视图中保留最近运行与本地图库，但不挂载 Advanced 表单。旧 autoPreview 设置不会为此页面选择生成后端。

使用图库中的“添加到对话”，多选文件一起添加，或将图库媒体拖到会话中。这些操作只填充输入框，不会提交请求；发送前请检查附件并说明修改或参考用途。图片作为视觉输入；视频作为文件附件，不代表所选模型能观看视频。

Content 模式提供已安装视频工作流发现、文生视频、图生视频、场景时间设置、Director 提示词片段、任务状态查询和影片组合。参考动画会将会话中选定的一张图片上传至 ComfyUI。创作工具保存需求与分镜修订，供后续编辑使用。影片组合支持裁剪、转场、场景音频和可选字幕轨道。不提供自动视频理解或上传视频暂存。配置与限制见[创作工具](../../api/tool-images/README.zh.md#understand-the-implementation)。

</details>

## 模型体验

### 图像会话

#### 模型看到什么

通过 `conversation.content` 提交的用户普通聊天请求和附件，以及已配置用户环境的工具。已安装的社区插件负责其工具指令和生成结果。

#### Token 影响

此页面不会向用户请求添加工作流目录或生成指令。

#### KV Cache 影响

请求使用标准会话前缀；此页面不会添加变化的工作流目录。

<a id="known-limitations-and-deferred-work"></a>

## 已知限制和后续工作

- 必须安装插件并配置服务提供商。启用插件包不能证明凭据有效或服务可用；工具失败仍会显示在聊天中。
- 生成速度、还原度和可用模型取决于所配置的图像服务。复用插件不能保证达到另一服务的图像质量。
- 刷新会重新检查插件可用性。页面不会静默安装、升级或捆绑第三方代码。
- 旧的直接生成历史保留在已保存会话中；媒体库中仍可查看最近运行与本地保存的文件。

此 UI 负责导航和会话引用，而不是独立的权威投影，因此没有发布不变量配套文档。
